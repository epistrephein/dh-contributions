# DH Contributions

Archive of the artifacts (abstracts, papers, slides, posters) produced for 
conferences, workshops and journals within the Digital Humanities context.

## Structure

Contributions are grouped by year, then by venue:

```
<year>/
├── <venue_1>/
│   ├── README.md   # event, place, date, URL, project presented
│   └── ...         # abstract, paper, slides, poster
└── <venue_2>/
```

Each venue folder has its own README with the details of the event and the
project presented.
