# DH Contributions

Archive of the artifacts (abstracts, papers, slides, posters) produced for
conferences, workshops and journals in the Digital Humanities.

## Structure

Contributions are grouped by year, then by venue:

```
<year>/<venue>/
├── README.md   # event, place, date, URL, project presented
└── ...           # abstract, paper, slides, poster
```

Each venue folder has its own README with the details of the event and the project presented.
